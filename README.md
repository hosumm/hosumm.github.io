## 项目简介

该项目是一个基于 **GitHub Pages** 的静态网站，旨在展示博客内容、文章和个人信息。项目采用了响应式设计，确保在各类设备上都能获得良好的浏览体验。

---

## 功能特性

- **页面布局**：  
  - **页眉**：包含站点标题和导航菜单。  
  - **文章内容**：支持文章分类、过滤和详细展示。  
  - **侧边栏**：提供快速访问的其他信息块。  
  - **页脚**：版权信息及其他补充内容。  

- **核心功能**：
  - 响应式设计，适配各种设备。
  - 使用 Flexbox 布局，提升页面灵活性。
  - 支持文章内容和侧边栏的动态调整。

---

## 技术栈

- **HTML5**  
- **CSS3**  
  - 使用 `Flexbox` 布局和媒体查询实现响应式设计。
- **JavaScript** （可选，未来可能添加动态交互）
- **GitHub Pages**  
  - 用于静态网站托管。
